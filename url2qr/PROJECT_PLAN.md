## 📋 프로젝트 개요

**URL2QR**은 URL을 입력하면 즉시 고화질 QR 코드를 생성하고, 클릭 한 번으로 **1200×1200px JPG 파일**로 다운로드할 수 있는 싱글페이지 웹 앱입니다.

| 항목 | 내용 |
|------|------|
| 타입 | 바닐라 HTML + CSS + JavaScript |
| 스택 | HTML5, Vanilla CSS, Vanilla JS, qrcode.min.js |
| 주요 기능 | URL → QR 생성, JPG 다운로드, URL 클립보드 복사 |
| 폰트 | Pretendard, Plus Jakarta Sans (Google Fonts) |
| 디자인 | 페일 오렌지 파스텔, 마우스 인터랙티브 그라데이션 배경 |

## 🔍 워크스루 — 기능별 동작 흐름

### 1️⃣ 초기 화면 (Hero 상태)

```
[배경] 페일 오렌지 파스텔 + 마우스 위치에 반응하는 동적 그라데이션
       + 4개의 살구빛 글로우 오브가 부드럽게 떠다님
[헤더] 좌측 URL2QR 로고 + 우측 "QR STUDIO" 배지 (오렌지 테두리)
[중앙] 히어로 타이틀: "링크를 입력하면 QR 코드가 완성됩니다"
       h1 강조 텍스트: #f97316 오렌지 그라데이션
[입력창] 라운드 캡슐형 폼 (오렌지 테두리 + 글로우)
```

### 2️⃣ QR 코드 생성 흐름

```
사용자 URL 입력
  → normalizeUrl()       : https:// 자동 추가
  → generateQrCode()     : QRCode 라이브러리 → 260×260 캔버스 렌더링
  → body.classList.add('has-qr') : CSS 상태 전환 트리거
      ├── 히어로 타이틀 사라짐 (opacity:0, max-height:0)
      ├── 입력창이 하단 도크로 스프링 애니메이션 이동
      └── QR 카드가 화면 중앙에 페이드인 (@starting-style)
```

### 3️⃣ QR 카드 상호작용

```
[호버] 카드 위로 6px 부상 + 오렌지 글로우 강화
       + 다크 오버레이 페이드인 → 오렌지 다운로드 아이콘 바운스

[클릭] downloadQrAsJpg() 실행
  → 1200×1200px Canvas 생성 (흰 배경 fill)
  → QR 매트릭스 직접 렌더링 (벡터급 선명도)
  → JPEG 품질 0.95로 변환
  → 파일명: qr_도메인_날짜시간.jpg
  → 자동 다운로드 트리거
  → 토스트 알림 (오렌지 아이콘) + 카드 바운스 애니메이션
```

### 4️⃣ 보조 액션

```
[URL 복사]    → navigator.clipboard.writeText() → 토스트 알림
[JPG 다운]    → downloadQrAsJpg() (카드 클릭과 동일)
[새로 만들기] → resetToInitial() → 초기 상태 완전 복원
[로고 클릭]   → resetToInitial() 동일 동작
```
